Notepadqq dnf repository

Add the repository (Oracle Linux / RHEL / EL clones 9, 10):

# prerequisites (OL9):
sudo dnf install -y oracle-epel-release-el9
sudo dnf config-manager --set-enabled ol9_codeready_builder
# prerequisites (OL10, dnf5):
sudo dnf install -y oracle-epel-release-el10
sudo dnf config-manager setopt ol10_codeready_builder.enabled=1

sudo dnf config-manager addrepo --from-repofile=https://saurabhahuja71.github.io/notepadqq/notepadqq.repo   # dnf5 (OL10)
sudo dnf config-manager --add-repo=https://saurabhahuja71.github.io/notepadqq/notepadqq.repo                # dnf4 (OL9)
sudo dnf install -y notepadqq

Packages are currently unsigned (gpgcheck=0). Per-distro trees live under /rpm/el<version>/<arch>/.
